IDENTIDAD Y PROPÓSITO
MercHosting es una aplicación de escritorio para Windows que permite alojar servidores Minecraft en la computadora del usuario. Eslogan: «Tu primer servidor no debería necesitar una mensualidad».

DECISIONES COMERCIALES
- Free: funciones esenciales completas, gratuitas.
- Supporter Edition: US$8, pago único, sin suscripción; únicamente temas, insignia, marcos, fondos, iconos, créditos opt-in y animaciones cosméticas.
- No vender recursos de PC, slots, número de servidores, mejor rendimiento, conectividad, backups, seguridad ni administración.

ALCANCE DE CONECTIVIDAD Y COLABORACIÓN
- Playit: cada usuario vincula su propia cuenta; integrar solo por medios oficiales/documentados.
- Simple Voice Chat: detectar y automatizar puerto UDP y túnel si proveedor/versión lo permiten; probar el flujo real.
- Compañeros: administración desde otra instalación de escritorio MercHosting con autorización por servidor. Canal seguro separado del túnel Minecraft.
- NO crear panel remoto web o móvil.

WEB OFICIAL
Sí crear una web de presentación y descarga: imágenes reales, explicación, funciones, FAQ, requisitos, novedades, versión, repositorio, redes y descarga Windows. La web no permite iniciar/detener ni administrar servidores, no incluye cuentas de control ni consola remota.

REGLAS
- No mockups que aparenten ser funciones reales.
- No botones decorativos.
- No métricas inventadas.
- No URLs ni perfiles inventados.
- No credenciales o secretos en frontend/repositorio.
- No perder mundos ni sobrescribir datos sin consentimiento y backup.
- Verificar APIs, licencias, límites y términos vigentes antes de integrar terceros.
- No asumir que una operación está disponible solo porque exista un CLI o agente.
- No ejecutar comandos de sistema arbitrarios enviados por compañeros.
- No usar Playit para transportar administración.
- No afirmar que la firma digital elimina automáticamente SmartScreen.
- No confundir el proyecto de la futura biblioteca multimedia de creadores (US$10) con MercHosting.

FORMA DE TRABAJO
Por cada módulo: inspecciona, diseña, implementa, prueba, registra resultados y documenta límites. Si una integración externa no puede automatizarse completamente, crea un flujo guiado honesto y explica qué falta. Conserva las funciones que ya sirven. Prioriza integridad de mundos, aislamiento de archivos, autorización en backend, recuperación, accesibilidad y claridad de usuario.
